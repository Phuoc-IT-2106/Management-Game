# PROPOSED PHASE 2 UPDATES TO CORE_LOOP.md

Status: PROPOSAL — targeted clarification only

## 1. Keep Existing Loop Unchanged

**DECISION — inherited**

Retain:

> Observe → Prioritize → Decide → Commit → Delegate / Intervene → Advance Time → Resolve → Review → Adapt

No contradiction was found that requires replacing the loop.

## 2. Clarify Advance Time

**PROPOSAL**

Add under `Advance Time`:

> The authoritative Simulation Tick is proposed as one calendar day, but the player normally advances to the next meaningful Decision Checkpoint rather than processing every day manually. Mandatory checkpoints include material competition decisions, contract/financial deadlines, sponsor deadlines, staff escalations, and failure/restructuring transitions.

## 3. Clarify Commit

**PROPOSAL**

Add:

> Commit converts a player choice into authoritative state changes and/or scheduled future obligations. A commitment may have immediate, delayed, or multi-horizon consequences; downstream outcomes are not all resolved at the moment of choice.

## 4. Clarify Delegate / Intervene

**PROPOSAL**

Add:

> Delegation operates inside an Authority Envelope: domain, scope, resource ceiling, strategic constraints, risk tolerance, escalation triggers, and review point. Staff can resolve delegated work automatically inside those boundaries and must escalate material out-of-bounds choices.

## 5. Clarify Resolve

**PROPOSAL**

Add:

> Resolution updates authoritative Company State and/or World State and may schedule delayed effects. Major consequences should be traceable to player commitments, delegated actions, competition outcomes, rival actions, or world changes.

## 6. Clarify Review

**PROPOSAL**

Add:

> Review distinguishes direct consequences, delayed consequences, delegated staff actions, rival/world changes, and unresolved uncertainty so the player can understand causal chains.

Move the following from generic open questions into explicit Phase 2 proposals:

- authority-envelope delegation;
- immediate/delayed consequence classes.

Keep unresolved:
