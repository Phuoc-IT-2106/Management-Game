# FAILURE RECOVERY MODEL

Status: Phase 2 — Core Loop & Simulation specialist proposal

## 1. Foundation

**DECISION — inherited**

Structural failure is real. Financial distress, debt pressure, forced downsizing, restructuring, or asset sales should usually create recovery gameplay before terminal game over.

**FACT**

Accepted Discovery direction identifies possible terminal conditions including bankruptcy, failure to meet debt obligations, sustained financial non-viability, and falling below a required minimum company-value threshold.

## 2. Failure-State Ladder

### State 0 — Healthy / Stable

**PROPOSAL**

The company can meet scheduled obligations with normal operations and has no structural failure trigger active.

### State 1 — Warning

**PROPOSAL**

Entered when forecasted liquidity / obligation coverage becomes unsafe within a defined near-term window.

Player feedback should identify the likely cause and the future deadline.

No forced action is required yet if obligations can still be met.

### State 2 — Distress

**PROPOSAL**

Entered when normal operations are insufficient to meet a material obligation or when a debt / minimum-value condition is breached or imminent.

Time should stop at a mandatory checkpoint.

The player must choose a recovery response.

### State 3 — Restructuring

**PROPOSAL**

Entered after the player takes extraordinary corrective action or after a missed obligation creates mandatory restructuring.

Possible first-slice actions:

- freeze discretionary spending;
- sell / transfer valuable player contracts;
- release or replace expensive staff where contract terms permit;
- renegotiate / refinance at worse terms;
- accept emergency financing;
- accept a less favorable sponsor deal;
- reduce future payroll commitments;
- shift from contend-now to rebuild / stabilize;
- sacrifice short-term competitive capability to restore viability.

### State 4A — Stabilized

**PROPOSAL**

Entered when near-term obligations are again serviceable and the company no longer violates active failure thresholds.

Consequences remain:

- weaker roster/staff;
- reputation damage;
- audience pressure;
- worse financing;
- reduced flexibility;
- lost opportunities.

Recovery should not instantly restore the pre-crisis position.

### State 4B — Terminal Insolvency / Campaign Failure

**PROPOSAL**

Terminal failure occurs only when at least one approved terminal condition is met **and no valid recovery route remains within the allowed recovery window**.

Candidate terminal paths:

1. mandatory obligations remain unpaid beyond grace/restructuring limits;
2. debt obligations repeatedly default with no financing/restructuring option;
3. company value remains below the required minimum threshold for the defined grace period;
4. the company has no viable operating path after required asset/contract liquidation.

Exact thresholds are balance parameters, not Phase 2 decisions.

## 3. Recovery-Option Generation

**PROPOSAL**

Recovery options must come from actual Company State, not from generic event choices.

Examples:

- high-value player under contract → sale option;
- expensive coach/staff contract → release / renegotiation option if allowed;
- strong audience but weak cash → emergency sponsor opportunity may exist;
- upcoming prize opportunity → high-risk continue option may exist;
- debt capacity remaining → refinancing option may exist;
- no liquid assets + no financing + missed mandatory obligations → terminal risk increases.

## 4. Failure Consequence Chains

**PROPOSAL**

Liquidity failure
→ emergency action
→ roster/staff/capacity sacrifice
→ competitive decline risk
→ reputation/audience pressure
→ sponsor value pressure
→ harder recovery.

Required counterweights:

- lower payroll after downsizing;
- cheaper talent opportunities;
- rebuild strategy;
- reduced expectations;
- improved future flexibility after obligations expire.

The model must support recovery, not only downward compounding.

## 5. Debt Role

**DECISION — inherited**

Debt is a strategic instrument, not free money.

**PROPOSAL**

First-slice debt needs only:

- principal / amount received;
- scheduled repayment / service;
- cost / unfavorable terms;
- maturity / deadline;
- default state;
- refinancing eligibility at abstract depth.

A detailed debt market is excluded.

## 6. Minimum Company-Value Failure Rule

**PROPOSAL**

Because company-value threshold failure is part of the accepted direction, Phase 2 should reserve a rule without fixing the number:

> If estimated company value remains below a campaign-defined minimum for a sustained grace period, the company enters mandatory restructuring and may reach terminal failure if value cannot be restored.

**OPEN QUESTION**

The exact valuation abstraction and threshold must be validated before prototype balance is locked.

## 7. Player Feedback Requirement

**PROPOSAL**

At every failure stage, the player should see:

- what threshold is threatened/breached;
- which commitments caused the pressure;
- time remaining;
- feasible recovery actions;
- immediate cost of each action;
- major known delayed risks.

## 8. Failure/Recovery Acceptance Criteria

**PROPOSAL**

The model is valid when tests demonstrate:

- overspending can create a real crisis;
- crisis does not instantly end the campaign;
- at least two materially different recovery strategies can exist in some states;
- recovery requires sacrifice;
- restructuring can return the company to a stable state;
- repeated inability to meet obligations can become terminal;
- recovery outcomes propagate to competition, reputation, audience, sponsorship, staff, and capacity.

## 9. Open Questions

**OPEN QUESTION**

- Length of warning and grace windows.
- Exact insolvency trigger.
- Company-value formula and floor.
- Which emergency financing options exist in the first prototype.
- Whether player removal from leadership exists at all; Phase 1 left this unresolved.
