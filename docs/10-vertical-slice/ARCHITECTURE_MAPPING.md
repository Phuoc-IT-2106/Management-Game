# Ownership and execution

Domain references System libraries only. Application references Domain and defines
typed operations, immutable observations and persistence ports. Infrastructure
implements JSON/content/file adapters. Godot and headless composition roots create
adapters; screen code consumes Application contracts.

Company owns people, contracts, financial items/settlements, commercial progress,
reputation/audience, preparation work/plan and authority. World owns calendar,
rivals, markets, schedule and the sole result records. Execution identity/revision,
receipts and seed are technical records, not another gameplay authority.

One writer stages immutable transitions. Exact retries return receipts; conflicting
IDs, stale revisions and invalid actions leave state unchanged. Pure Competition
emits outcomes; Finance and Commercial consume once. Each daily phase commits its
next cursor; competition and immediate consumers commit atomically. Save only at
committed boundaries. Rebuild derived values/observations on load.
