# Director recommendation

**ACCEPT LIST-FIRST / MAP-OPTIONAL**

Use the structured company hierarchy as the primary navigation model. Retain the
bounded map as an optional overview while it has demonstrated inspection value.
This is a recommendation for Director disposition, not a new accepted DEC entry.

Both representations expose the same matters, evidence and exact return context.
The matched task scripts require the same activations and context transitions.
The shared compact header, inspector and Affairs solve the principal 720p access
problems. Those gains do not depend on the map.

The map has a real countervailing advantage: parallel lanes consume less height
and show support relationships without inspection. The tree has fewer Controls
and a simpler sequential composition, but it does **not** win every density
measurement. Its implementation advantage is bounded, not an order-of-magnitude
saving. See the direct numbers in COMPARISON_MATRIX.md.

There is no human evidence that simultaneous relationship labels improve
comprehension, orientation, company feel or repeated task performance enough to
justify making the map mandatory. Given the brief's burden of proof on the map,
the conservative choice is list-first, preserving the map for optional overview.
Do not describe this as proof that users prefer or perform better with lists.

Consequences if accepted: make list the default in a separately authorized
product integration, preserve shared navigation and contextual inspector, and
keep a map toggle only while its maintenance cost remains small. No generic graph
investment follows. Neither presentation requires changes to Company/World,
gameplay commands, saves or identity persistence. Rejecting both is unwarranted:
both remain readable and the defined navigation contracts are verified.

Director may validate the remaining hypothesis with counterbalanced human tasks:
ask participants to explain ownership versus shared support and the sponsor's
preparation consequence, then compare wrong turns and unaided explanations. No
satisfaction score, find time or human approval has been supplied for this gate.

Stop here. Stage 4, live identity/observation integration, Sponsor implementation,
final art and all DV/QG dispositions remain outside this completed assignment.
