# 1280×720 review

Primary stress viewport: 1280×720 render pixels, Compact density, text scale 1.
Both representations use the same fixed 380px inspector and canonical readable
17px body / 16px label / 14px annotation roles. No font/token changes.

| Observation | Actual result |
| --- | --- |
| Identity header including fixture notice | 73px measured, versus roughly 147px in historical Stage 3 sponsor image |
| Persistent context | Short company name, fixture notice, day 8/checkpoint day 14, full selected semantic path |
| Main reading region, drawer collapsed | 468px high in both modes |
| Normal representation content | Map 414px; tree 454px |
| Selected sponsor content | Map 437px; tree 477px |
| Sponsor inspector | 375px content; summary, action and complete evidence fit without scrolling |
| Preparation inspector | 323px content; unknown basis and entry fit without scrolling |
| Quiet inspector | 435px; no urgent message and ordinary situations visible |
| Affairs expanded | 82px two-row drawer; reading region becomes 386px |
| Horizontal overflow | None in the five matched states or preserved native fixture checks |

Identity reduction is not the entire reading-space gain: a persistent 35px Affairs
button now occupies the bottom strip. This intentional trade keeps the next dated
matter discoverable while the current day/checkpoint remain in the toolbar.

The original [Stage 3 sponsor image](../evidence/candidates/sponsor-1280x720.png)
has its entry action below the inspector fold. The refined
[map](evidence/candidates/map-sponsor-1280x720.png) and
[tree](evidence/candidates/list-sponsor-1280x720.png) expose it with the complete
decision summary/evidence. This is geometry and visual inspection, not find-time
or comprehension proof.

Remaining pressure: selected tree content exceeds its region by 9px, clipping part
of the final Affairs function row. The permanent Affairs button remains fully
visible, and task targets require no explicit scrolling. With the drawer open,
lower structure may need vertical scrolling in both views. The map has more spare
height. Longer full identity is deliberately on inspection, with a short name in
the persistent shell; no name is truncated out of the data or used for routing.

No severe readability loss or broad architecture rewrite was required. 1080p
recomputes layout with an 828px reading region. Neither render viewport is evidence
of physical Windows DPI behavior, mixed monitors, 150% text or all-language fonts.
