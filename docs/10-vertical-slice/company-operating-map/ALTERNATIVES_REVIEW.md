The hybrid uses native vertical/horizontal containers, labelled containment and
direct support links. No edges engine or arbitrary positioning. The company root
is shared by both lanes; functions are capabilities, not owned competitive units.
One selected scope/situation drives one inspector. Two emphasized situations at
most; all four remain directly reachable. No gameplay score ranks attention.

Hypothesis: attached situations explain where work belongs better than flat tabs.
This is not a usability finding. Director timed tasks compare map/list with the
existing internal UI before acceptance. Reject the map if list clarity wins.
