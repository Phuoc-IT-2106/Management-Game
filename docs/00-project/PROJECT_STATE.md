# PROJECT STATE

Version: 0.1
Phase: Discovery

## Current Objective
Define the product direction, management fantasy, simulation boundaries, and minimum viable strategic loop before major implementation decisions.

## Known Facts
- The game is intended for PC.
- The core genre is business strategy / management simulation.
- The initial theme is a professional esports organization.
- The long-term company may expand into other sports and commercial sectors.
- The project will use AI-assisted development and multi-agent coding.
- The game should avoid repetitive fixed loops.

## Working Assumptions
These are not final decisions.

- The player controls company-level strategy rather than directly controlling every operational action.
- Esports is the first vertical slice because it provides a focused environment for validating the core management model.
- Future industries should reuse company-level systems instead of becoming isolated mini-games.
- Simulation depth should come primarily from interactions between systems.
- The first prototype can be UI-light or headless.
- A data-driven architecture will likely be important.

## Decisions Locked
None yet beyond the general project direction.

## Decisions Not Yet Locked
- exact player role
- simulation realism level
- time scale
- business granularity
- engine
- UI framework
- match simulation depth
- world scale
- fictional vs real-world-inspired industries
- failure conditions
- progression model
- expansion model
- multiplayer / online features
- modding support

## Current Priority
Finish Discovery before committing to detailed architecture or production code.
