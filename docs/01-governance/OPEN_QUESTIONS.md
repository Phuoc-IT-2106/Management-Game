# OPEN QUESTIONS

Status: ACTIVE — Phase 3 Prototype

## Test During Phase 3
- Are four rivals necessary, or do fewer create equivalent pressure?
- Is the 84-day integrated horizon necessary, or can a shorter run provide equivalent evidence?
- Are 8–10 matches necessary?
- Are all three information domains useful?
- Does Company Value produce meaningful decisions or only summary information?
- How much Reputation and Audience inertia is needed?
- What overload curve produces useful pressure without arbitrary cliffs?
- How strong should coach tendencies affect recommendations?
- Do sponsor restrictions materially change acceptance/rejection decisions?
- Do opponent-specific preparation and strategy exposure overlap too much?
- Is one flex substitute sufficient to create useful lineup decisions?
- Should Commercial Value be visible, estimated, or mostly explanatory?

## Deferred Until After Prototype
- final insolvency/game-over thresholds;
- founder/owner-CEO versus hired CEO identity;
- removal from leadership;
- final victory conditions;
- final season/calendar structure;
- real esports discipline selection;
- deep drafting or mid-match tactical control;
- additional staff roles and deep relationships;
- facilities;
- multi-team organization;
- additional esports titles;
- non-esports expansion;
- media, merchandising, events and M&A;
- advanced debt markets;
- final accounting model;
- production UI/UX;
- engine/framework;
- production architecture and final persistence;
- modding and multiplayer.

## Governance Rule
Do not answer a deferred question through implementation convenience. If prototype implementation would require changing an accepted project decision, return the conflict to Project Director.
