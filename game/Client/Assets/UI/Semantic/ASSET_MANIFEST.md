**Single source of truth for the mapping:** `game/Client/UI/Contracts/SemanticAssets.cs` (`SemanticConcept`,
`SemanticAssets`). UI code asks for a concept, never a file path. `SemanticArt` (`UI/Identity/SemanticArt.cs`) loads
and draws it. `tests/UiKit` checks the mapping, file presence and the source hashes below.

Each concept has two files:
- `*.png`: the canonical supplied source. It is never loaded at runtime, and its bytes must match the hash below.
- `*.webp`: the runtime derivative, the same image resized without cropping to at most 512 px. Godot imports it with
  mipmaps; the `.import` files are generated by Godot (`--import`) and committed.

If a runtime file cannot be loaded, `SemanticArt.Create` falls back to the concept's own vector icon
(`SemanticAsset.FallbackIcon`). This is the only fallback path; another concept's art is never substituted.

**Transparency (checked 2026-10-08).** Every source PNG and runtime WebP is RGBA with a fully transparent background:
- the corners are alpha 0;
- there are no opaque background pixels;
- the object's interior is alpha 250–255, and only its anti-aliased edge is partly transparent.

Batch `portal_assets_v2` derivatives use the same pipeline as v1:
- each source is 1024 × 1024 RGBA with transparent background;
- each WebP is resized with Lanczos to 512 px, encoded at quality 90;
- the `.import` files are generated by Godot, with `mipmaps/generate=true` on the WebP like v1.

## Hard constraints

- Do not regenerate, repaint, recolor, crop or substitute these assets, and do not use one for an unrelated concept.
- Module art appears only for its own section. Region headers and controls such as save, load, arrows, filters and
  warnings are always vector icons.
- The Competition trophy is a module symbol. It never stands for a title or award the player has actually won.
- Do not invent portraits, staff photos, event or news photos, sponsor logos, crests or character art. Missing art
  falls back to the generated identity marks (crests, brand symbols), neutral plates, or text.
- Values shown in mockups are visual examples, not game data.
